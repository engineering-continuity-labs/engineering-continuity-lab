# v0.5 manager presentation handoff

PO decision: present the accepted twelve-section manager review as a standalone
offline document with an explicit SYNTHETIC demo link from Overview. Keep the
four existing primary areas. Opening this example is a deliberate navigation;
it does not compose or replace a user's loaded Git report. First screen shows
system, UTC period, source boundaries, independent delivery/defect/build values,
attention findings and unavailable evidence. No combined score or person ranking.
Snapshot legacy cards use original trace summary, review collection status,
component-row counts and each original requirements metric/value/status. An
explicitly bounded preview names finding types/severity/scope and historical
component risk/concentration with source time and links to full evidence. Missing
dimensions and new component mapping remain explicitly unavailable; old component
rows never imply new flow/defect membership.
Expose component, metric and finding supports with native details controls.
Offer browser print and an embedded machine package for audit. A public acquisition
or composition CLI and browser package import remain separate increments.

Architect: Python renders only packages accepted by the existing recomputing
import boundary. JSON remains normative; presentation performs no alternate
metric derivation. HTML escapes text and script-data delimiters, uses inline CSS,
no remote resources or network code, and rejects output exceeding 32 MiB. Demo
generation uses the checked-in SYNTHETIC package and explicitly passes the demo
provenance assertion; renderer defaults to OFFLINE DECLARED and never infers
provenance from aliases or names. Existing browser retains its
four areas and links to the generated offline document.

QA before implementation: exercise all twelve sections, exact source values and
missing/partial dimensions, source and threshold drilldowns, embedded package
roundtrip, deterministic output, HTML escaping, no network dependencies, native
keyboard controls, print styles, output limits, generator freshness and legacy
UI regressions. Real browser/mobile/print usability is MANUAL until inspected.
Relevant FR501/502/508–511/513, NFR501–504; AC501/502/517–521. Independent full
diff review and green final-head CI required before merge.
