Snapshot = approved alias, repository, exact revision and SHA256 of canonical public traceability section, including boundaries/configuration. Recompute, check all repository/revision/project scopes and actual WI/component membership. Optional no-code v4 is represented using an explicit empty unsupported trace context (no invented WI/components); code/execution remain unavailable. Set collections canonicalize full identity/normalized UTC timestamp; semantic nodes/support sequences retain order. No arbitrary inference or new mathematics.

It exposes complete typed/scoped/versioned references, independent artifact populations, associations, observations, lookups, snapshot and limits. JSON compatibility input may be retained as documented alternative but TOML example and command are primary. Unknown keys rejected everywhere. Metadata/lookup declarations remain source-owner assertions. No title/content/private mappings.

CLI boundary reads only two named regular files, max8MiB each, strict UTF-8; JSON depth64/duplicate keys/nonfinite/lone surrogates reject, TOML duplicate/unknown/nonfinite/datetime types reject unless required timestamp string. Parse before derivation; output optional named file written atomically after complete validation, otherwise stdout. No input overwrites or special output files; fixed errors (invalid/unapproved2, I/O3); no paths/source/exception text. No network or credentials. Generic argument errors sanitized for this command.

Presentation adapts loaded validated verification_evidence to existing presenters; report-owned evidence takes precedence over separately selected showcase-only context. Add advanced loaded inspector in existing assurance area, retain isolated scenarios. Header export retains full v4. Four navigation groups and sample separation remain unchanged.
